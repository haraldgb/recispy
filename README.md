# Recispy

Mobile-first PWA for storing recipes extracted by AI from URLs.

See `docs/superpowers/specs/2026-04-11-recispy-design.md` for the design.

## Layout

- `server/` — Hono + Drizzle backend
- `web/` — Vue 3 + Vite frontend
- `deploy/` — systemd unit, Caddyfile snippet, Postgres bootstrap SQL

Implementation in progress.
